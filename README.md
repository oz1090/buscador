# Buscador de Pacientes

App para el celular (instalable) que busca por CURP, nombre o apellidos en el paquete `.bpaq` de Urgencias, Lesiones y Egresos.

Este repositorio solo contiene el programa. Los datos de pacientes nunca se suben: el paquete se abre y se guarda solo en el celular.
